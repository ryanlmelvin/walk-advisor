# Walk Window icon

`walk-window.png` is the full-resolution master, created with OpenAI's built-in image generation tool. The generation prompt is in `prompt.txt`.

The icon shows an open window framing a person walking a dog. The files in `public/icons/` are resized PNG exports. The separate maskable export adds space around the master to protect the window and figures from launcher crops. The master is not included in the website download.

No stock artwork, icon library, or third-party asset was used.
